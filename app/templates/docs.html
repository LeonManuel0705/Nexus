Quick Start

VoiceNotes is a voice transcription application that runs entirely on your computer. Here's how to get started:

  1. Launch VoiceNotes by running ./start.sh in your terminal
  2. Open your browser to http://localhost:5050
  3. Wait for the models to initialize (first launch may take a few minutes)
  4. Select your language (English or German)
  5. Click the record button and start speaking

Tip: For the best results, use a good quality microphone and speak clearly at a normal pace.

Requirements

System Requirements

  • macOS, Windows, or Linux
  • Python 3.9 or higher
  • 4GB RAM minimum (8GB recommended)
  • 2GB free disk space for models

For Apple Silicon (M1/M2/M3)

VoiceNotes uses MLX for accelerated AI inference on Apple Silicon Macs. This provides faster and more accurate transcription enhancement.

Installation

Automatic Setup

Run the offline setup script to download all required models:

./setup_offline.sh

This will download:

  • Whisper speech recognition models (~650MB)
  • LanguageTool language data (~350MB)
  • Speaker recognition model (~80MB)
  • MLX AI model for Apple Silicon (~500MB)

Recording

Starting a Recording

Click the large record button in the center of the screen. The button will turn red to indicate recording is active.

Live Transcription

As you speak, you'll see your words appear in real-time below the record button. The text updates every few seconds as the AI processes your speech.

Stopping a Recording

Click the record button again to stop. Your recording will be automatically saved as a note in the current folder.

Voice Profiles

Voice profiles allow you to filter recordings to include only specific speakers.

Creating a Profile

  1. Click the voice filter button (person icon)
  2. Click "Create New Profile"
  3. Enter a name for the profile (e.g., "Professor Smith")
  4. Record a 30-second sample of the person speaking
  5. Click "Save Profile"

Using Voice Filter

Select a profile from the dropdown to activate voice filtering. Choose between:

  • Include Mode: Only transcribe when this voice is detected
  • Exclude Mode: Transcribe everything except this voice

Organizing Notes

Folders

Create folders to organize your notes by course, project, or any category. Right-click on the sidebar to create a new folder or subfolder.

Tags

Add tags to notes for quick filtering. Click on a note to open the detail panel, then add tags in the tags section.

Search

Use the search bar at the top of the sidebar to find notes by content. The search looks through all note text and titles.

Exporting

Export your notes in multiple formats:

  • Word (.docx): Professionally formatted documents for Microsoft Word, Google Docs, or any word processor. Includes proper headings, paragraphs, and styling.
  • Markdown (.md): For use in note-taking apps like Obsidian or Notion
  • Plain Text (.txt): Universal format for any application

You can export individual notes or entire folders at once.

Settings

Language

Select between English and German for both the UI and transcription language.

Theme

Toggle between light and dark mode using the sun/moon icon in the navigation bar.

Voice Filter Threshold

Adjust the sensitivity of voice filtering. Lower values are more strict, higher values are more permissive.

Troubleshooting

Microphone not working

Make sure your browser has permission to access the microphone. Check your system sound settings to ensure the correct microphone is selected.

Slow transcription

Transcription speed depends on your hardware. On slower machines, try using shorter recording sessions.

Models not loading

Run ./setup_offline.sh to download all required models. Make sure you have enough disk space.

Port already in use

If port 5050 is already in use, stop any other applications using that port or modify the port in app.py.
